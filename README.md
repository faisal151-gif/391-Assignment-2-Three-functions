- css/style.css - styles for all three pages
- js/fortune.js, js/stopwatch.js, js/todo.js - JavaScript for each question


## What each page does

1. Fortune Generator: shows a random fortune from an array every time the page loads. The four colour buttons next to the box change the text colour, background colour, border colour, font size and font family.
2. Stopwatch: counts 3, 6, 9 ... and stops at 30 seconds. Stop pauses it, Start continues from where it stopped and Reset sets it back to 0.
3. To-Do List: type a task and click Add. Tick the checkbox to mark it as done or click Delete to remove it. Tasks are saved in localStorage, so they are still there after refreshing the page.
